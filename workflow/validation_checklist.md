# LLM Wiki 與 HTML 簡報檢查清單

## A. Ingest 前（資料入口檢查）
- [ ] 至少有 5 篇獨立知識文件。
- [ ] 每篇有穩定 ID、標題、摘要與關鍵詞。
- [ ] 數字均有單位及比較基準。
- [ ] 三個期間日期沒有混用。
- [ ] 對照組冰箱扣除流程已註明，且不重複扣除。
- [ ] 不存在自行補造的溫度、濕度、日照或設備時數。

## B. Wiki 查詢後（檢索／內容檢查）
- [ ] 每張簡報至少能對應一個 Wiki ID。
- [ ] 摘要沒有把兩個不同單位的資料混在一起。
- [ ] 若檢索結果不足，重新查詢或縮小該頁主張，而不是自行補資料。
- [ ] 重要數字可回到 WIKI-03 或 WIKI-04 核對。
- [ ] 因果限制可回到 WIKI-05 核對。

## C. HTML 產生後（輸出檢查）
- [ ] 403.30、761.30、358.00、47.02% 正確。
- [ ] 差異率分母使用對照組數值。
- [ ] 圖表單位標示為 kWh／分地。
- [ ] 沒有宣稱已證明白漆造成 47% 節電。
- [ ] 沒有沒有來源的減碳量、溫度或濕度數字。
- [ ] 上一頁／下一頁、鍵盤導覽與手機版正常。
- [ ] 所有內部連結可開啟。

## 主要錯誤模式與處理

| 錯誤模式 | 檢查提前到哪裡 | 修正方式 |
|---|---|---|
| 每分地與總耗電量混淆 | Ingest 前 | 每份數據標註單位及正規化方式 |
| 差異率算錯或分母錯誤 | 數據摘要生成前 | 用 WIKI-04 公式重算並與累計核對 |
| 把差異寫成因果 | 查詢摘要時 | 強制檢索 WIKI-05 的研究限制 |
| 簡報沒有來源 | 每頁摘要產生時 | 每頁附 Wiki ID，無來源不進入下一步 |
| HTML 內容溢出或導覽錯誤 | 輸出後 | 瀏覽器逐頁檢查，局部重生問題頁 |
